# Security

Backstage records meetings, reads the screen and serves a page on the local
network. If you find a way to read someone's sessions, reach the phone page
without the key, or make the AI tool do more than answer, please report it
privately: open a private security advisory on this repository (Security >
Report a vulnerability) instead of a public issue.

Include what you did, what happened, and the Backstage version or commit.

What is already known and accepted is listed in
[docs/privacy-and-security.md](docs/privacy-and-security.md).
